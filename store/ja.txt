［タイトル］（パッケージから取得されます。確認用）
Arcish タブ管理拡張

［概要］（パッケージから取得されます。確認用）
Chrome のタブ体験を大幅アップデート！

［説明］
Arcish は、Chrome のサイドパネルにタブを整理するためのサイドバーを追加します。

・Favorites とピン留め — タブを閉じてもピンは残り、ワンクリックで開き直せます。
・Space — 用途ごとのタブのまとまり。それぞれに色を付けられ、スワイプで切り替わります。
・フォルダ — ピンをまとめ、入れ子にでき、フォルダごとにアイコンを選べます。
・Live Folder — プルリクエスト、Issue、フィードを自動で更新し、ビルドの状態も表示します。
・コマンドバー — タブ、ピン留め、ブックマーク、履歴への移動や操作の実行をキーボードから。
・ライブラリ — アーカイブしたタブ、ダウンロード、Space、Boost をまとめて検索できます。
・スプリットビューと Little Window — 2 つのページを並べて表示、または小さなウィンドウで確認。
・Boost — サイトごとの独自 CSS と、見たくない要素を消す Zap。

Arcish は Chrome を補助するもので、乗っ取りません。Chrome 本来の動作を変える機能（使っていないタブを閉じる、Space をタブグループとして表示する、タブストリップでの操作を上書きする）は、オンにするまで働きません。

データは端末の中に保存されます。Arcish にはサーバーも解析もありません。通信するのは、Live Folder で自分で設定した取得先（GitHub、Hacker News、入力したフィードのアドレス）だけです。

ソースコード: https://github.com/KikuchiTomo/arcish

======================================================================
プライバシーへの取り組み
======================================================================

［単一用途］
Arcish はタブ管理の拡張機能です。Chrome のサイドパネルにサイドバーを追加し、ユーザーがウィンドウ内のタブを整理して行き来できるようにします。タブをまとめる Space、タブを閉じても残る Favorites とピン留め、フォルダ（ユーザーが選んだフィードの内容が入るフォルダを含む）、閉じたタブのアーカイブ、タブへ移動するためのコマンドバーがその内容です。以下の権限はすべてこの 1 つの用途のために使います。

［tabs が必要な理由］
サイドバーはウィンドウのタブの一覧なので、各タブのタイトル、アドレス、アイコンが必要です。これらはこの権限がないと取得できません。また、サイドバーでのユーザーの操作に応じてタブを選択する、開く、閉じる、移動する、固定する、固定を解除するためにも使います。Favorites やピン留めに対応するタブがすでに開いている場合に、重複して開かずそのタブを見つけるためにも使います。

［tabGroups が必要な理由］
既定ではオフの任意設定「タブグループと連動」でだけ使います。ユーザーがオンにすると、各 Space を Space の名前と色を付けた Chrome のタブグループとして表示し、ユーザーがそのグループに加えた変更を読み取って、サイドバーとタブストリップの内容を一致させます。

［sidePanel が必要な理由］
この拡張機能の画面は、Chrome のサイドパネルに表示するサイドバーそのものです。サイドパネルを登録するため、およびツールバーのボタンを押したときやコマンドバーで「サイドバーを開く」を選んだときに開くために必要です。

［storage が必要な理由］
ユーザーがサイドバーで作ったものを端末内に保存します。Space、Favorites、ピン留め、フォルダ、閉じたタブのアーカイブ、Live Folder の取得結果、Boost、設定（chrome.storage.local）と、ブラウザの起動中に各タブがどの Space に属しているか（chrome.storage.session）です。同期も外部への送信もしません。

［alarms が必要な理由］
サイドバーを閉じていてサービスワーカーが停止している間も動かす必要がある、2 つの定期処理に使います。ユーザーが選んだ間隔での Live Folder の更新と、ユーザーが自動アーカイブを有効にした場合に限り、指定した時間使われていないタブの確認です。

［contextMenus が必要な理由］
右クリックメニューにタブ管理の操作を追加します。リンク上では「Little Window で開く」「スプリットビューで開く」「リンクを Space にピン留め」、ページ上では「Favorites に追加 / 解除」「Space にピン留め / 解除」「Little Window で開く」「Zap: このページの要素を消す」、ツールバーのボタン上では「Little Window」「コマンドバー」「設定」です。

［scripting が必要な理由］
サイドバーには、音声を再生中のタブの再生／一時停止ボタンが出ます。押されたときに、拡張機能に同梱している小さな関数を 1 つそのタブで実行し、メディア要素を一時停止または再開します。この権限で注入するのはそれだけで、ページの内容は読み取りません。

［favicon が必要な理由］
タブ、Favorites、ピン留め、アーカイブ、コマンドバーの検索結果の横に、サイトのアイコンを表示します。タブを閉じているピン留めのアイコンも表示します。アイコンは favicon API を通じて Chrome 自身のローカルのキャッシュから取得するので、そのための外部への通信は発生しません。

［history が必要な理由］
コマンドバーで、タイトルやアドレスの一部を入力して以前開いたページを探せるようにします。履歴を検索するのはユーザーがコマンドバーに文字を入力している間だけで、一致したものを候補として表示します。履歴の内容を保存したり外部へ送信したりはしません。

［bookmarks が必要な理由］
コマンドバーで、ブックマークもタイトルやアドレスで検索し、キーボードから開けるようにします。読み取りだけで、ブックマークの作成、編集、削除は行いません。

［system.display が必要な理由］
Little Window は、ページを手早く確認するための小さなブラウザウィンドウを開きます。複数のディスプレイを使っている場合も含めて、そのウィンドウを見えている画面の中に収めて配置するために、ブラウザがある画面の作業領域を読み取ります。

［clipboardWrite が必要な理由］
「URL をコピー」で現在のタブのアドレスをコピーします。キーボード ショートカットやコマンドバーから実行でき、その場合はページ自体がクリックを受けていないため、この権限がないとコピーできません。クリップボードの読み取りは行いません。

［downloads が必要な理由］
サイドバーのライブラリに、最近のダウンロード（ファイル名、状態、アイコン）を一覧表示し、ダウンロードの進行中は表示を更新します。ダウンロードしたファイルをフォルダで表示する操作にも使います。

［downloads.open が必要な理由］
ライブラリで完了したダウンロードをクリックすると、そのファイルを開きます。Chrome では、ダウンロードしたファイルを開くのにこの権限が別に必要です。

［ホスト権限が必要な理由］
Arcish はユーザーが開いているどのサイトでも動く必要があり、対象のサイトをあらかじめ列挙できません。
1. コマンドバーは、どのサイトでも現在のページの上に重ねて表示します。
2. Boost は、ユーザーが設定したサイトで、ユーザーが書いた CSS を適用し、Zap で選んだ要素を非表示にします。
3. メディアの操作は、音声を再生しているタブがどのサイトであっても一時停止と再開を行います。
4. Live Folder は、ユーザーが入力したフィードのアドレス（どのホストでもあり得ます）と、GitHub および Hacker News の API から取得します。
コンテンツ スクリプトは、これらの機能が使われるまでページに何も追加しません。ページの内容を読み取ったり送信したりもしません。

［リモートコードを使用していますか］
いいえ、リモートコードを使用していません。
JavaScript はすべてパッケージに含めています。eval は使わず、サーバーからスクリプトを読み込むこともありません。通信で受け取るもの（Live Folder 用の JSON とフィードの XML）はデータとしてのみ扱います。

［データ使用 — チェックを入れる項目］
チェックを入れる:
  ☑ ウェブ履歴
      タブのタイトルとアドレスをサイドバーに表示し、ピン留め、Favorites、アーカイブのために端末内に保存します。コマンドバーは閲覧履歴を検索します。
  ☑ 認証に関する情報
      ユーザーが Live Folder 用に GitHub のトークンを入力した場合だけです。端末内に保存し、api.github.com にだけ送信します。
チェックを入れない:

  ☐ 位置情報

  ☐ ウェブサイトのコンテンツ   （ページの内容は読み取りません。Live Folder の項目はユーザーが設定した取得先のものです）
